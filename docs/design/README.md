## توکن‌ها در کد

رنگ‌ها و قلم‌ها در `frontend/src/app/globals.css` تعریف شده‌اند و از همان نام‌های معنایی (`bg`، `surface`، `text`، `muted`، `accent`، `ink` …) در همه‌ی کامپوننت‌ها استفاده می‌شوند، پس تغییر هویت از همین یک فایل ممکن است.

- **تم:** پیش‌فرض روشن؛ تیره با انتخاب بازدیدکننده (کوکی `threevda_theme`) یا ترجیح سیستم. بخش‌های «جوهری» (هیرو، پایین صفحه، نوار کناری پنل) در هر دو تم تیره می‌مانند.
- **قلم‌ها:** Bodoni Moda و Manrope برای لاتین، Vazirmatn (وزن ۲۰۰ تا ۶۰۰) برای فارسی؛ همه خودمیزبان.
- **حرکت:** فقط جابه‌جایی و کراس‌فید روی عکس؛ **هیچ متنی محو و ظاهر نمی‌شود** (کنتراست در همه‌ی لحظه‌ها حفظ شود) و همه‌چیز با «کاهش حرکت» خاموش می‌شود.
- **کنتراست:** همه‌ی جفت‌های متن ≥ ۴٫۵ به ۱ در هر دو تم؛ خط زیر فیلدها ۶۰٪ رنگ متن (کنتراست اجزای غیرمتنی ≥ ۳ به ۱).
