# فاز ۲ — سیستم طراحی، سایت عمومی و CMS (برنامه‌ی تفصیلی)

**هدف:** سایت عمومی دوزبانه (فارسی RTL و انگلیسی LTR) با هویت بصری تأییدشده، که **همه‌ی متن‌ها و تصاویرش از پنل قابل تغییر است**.
**سند طراحی:** `docs/superpowers/specs/2026-10-02-photographer-platform-design.md`، **نقشه‌ی راه:** `docs/superpowers/plans/2026-10-02-roadmap.md`

## تصمیم‌های این فاز

| موضوع | تصمیم |
|---|---|
| تأیید برند | پالت «استودیوی تاریک، نور گرم» و فونت‌ها (Vazirmatn، Fraunces، Inter) تأیید شد. لوگو فعلاً نیست؛ تا آمدنش نام برند به‌صورت متن نمایش داده می‌شود و لوگو از «تنظیمات سایت» در پنل بارگذاری می‌شود |
| ویرایش‌پذیری | سه نوع داده‌ی قابل‌ویرایش: **تنظیمات سایت** (نام، شعار، تماس، شبکه‌ها، لوگو، تصویر OG)، **بلوک‌های متن/تصویر** (هر عنوان و متن ثابت صفحه‌ها با یک کلید) و **آیتم‌های تکرارشونده** (اسلاید هیرو، خدمت، مرحله‌ی همکاری، مشتری، نظر، پشت صحنه، پرسش، پیوند منو) |
| بلوک‌ها | فهرست کلیدها در `apps/cms/blocks.py` تعریف می‌شود و ردیف‌ها هنگام اولین خواندن ساخته می‌شوند؛ افزودن یک جایگاه جدید migration نمی‌خواهد. صفحه‌ها هیچ متنی را در کد ثابت نمی‌کنند |
| دوزبانه بودن | هر فیلد `_fa` و `_en` دارد. اگر یکی خالی باشد، سایت متن زبان دیگر را نشان می‌دهد |
| رسانه | همه‌ی تصاویر از کتابخانه‌ی Media (فاز ۱) انتخاب می‌شوند. هر استفاده یک `MediaReference` می‌سازد: فایلِ در حال استفاده حذف نمی‌شود و تعداد استفاده در کتابخانه دیده می‌شود |
| API عمومی | `GET /api/public/site` یک پاسخ کش‌پذیر با همه‌ی محتوای خانه (فقط آیتم‌های منتشرشده). نمونه‌کار و پکیج در بخش ۲.۲ اضافه می‌شود |
| کش Next | صفحه‌ها با ISR ساخته می‌شوند و پس از هر تغییر در پنل، revalidate هدفمند فراخوانی می‌شود (بخش ۲.۴) |

## APIهای بخش ۲.۱

| متد و مسیر | توضیح |
|---|---|
| `GET /api/public/site` | بدون ورود؛ تنظیمات، همه‌ی بلوک‌ها و آیتم‌های منتشرشده‌ی هر مجموعه |
| `GET/PUT/PATCH /api/admin/cms/settings` | تنظیمات سایت |
| `GET /api/admin/cms/blocks/` و `PATCH /api/admin/cms/blocks/{key}/` | فهرست (به ترتیب گروه) و ویرایش متن و تصویر هر بلوک. کلید جدید ساخته یا حذف نمی‌شود |
| `GET/POST/PATCH/DELETE /api/admin/cms/items/` | آیتم‌ها؛ فیلتر `?collection=` |
| `POST /api/admin/cms/items/reorder/` | ترتیب یک مجموعه؛ فهرست باید دقیقاً همه‌ی آیتم‌ها را شامل شود |

## گیت تکمیل فاز ۲

- همه‌ی فیلدهای عمومی (متن و تصویر) از پنل قابل ویرایش‌اند
- API عمومی فقط محتوای منتشرشده را برمی‌گرداند و هیچ فیلد خصوصی (فایل اصلی، یادداشت داخلی) ندارد
- E2E: ایجاد در پنل ← دیدن در سایت ← ویرایش ← حذف
- RTL و LTR، axe بدون نقض جدی، Lighthouse ≥ ۹۰
