# Reel تبلیغاتی 3evda.com

ویدیوی عمودی ۱۰۸۰×۱۹۲۰، ۳۰ ثانیه، ۳۰ فریم، با موسیقی اختصاصی ۱۲۸ BPM (ساخته‌شده با کد، بدون مشکل کپی‌رایت).
هر کات دقیقاً روی ضرب موسیقی است و آخر ویدیو بی‌درز به فریم اول برمی‌گردد (لوپ).

## سناریو

| زمان | صحنه |
|---|---|
| ۰ تا ۱٫۹ | قلاب: عکس معمولی با موبایل، «عکس منوی شما هنوز این شکلیه؟»، مهر «معمولی!»، شاتر |
| ۱٫۹ تا ۵٫۶ | فلش، همان غذا با عکاسی حرفه‌ای، اسلایدر قبل/بعد، نام سودا رحیم‌پور |
| ۵٫۶ تا ۱۵ | مونتاژ ۱۰ عکس با ویزور دوربین و کلمه‌های حسی (نور، رنگ، بافت، عطر، …) |
| ۱۵ تا ۱۸٫۸ | بریک: «هر عکس، یک داستان. نوبت برند توئه. آماده‌ای؟» با رایزر |
| ۱۸٫۸ تا ۲۰٫۶ | دراپ: خدمات (منو، فروشگاهی، کمپین، اینستاگرام) |
| ۲۰٫۶ تا ۲۶٫۳ | عکس‌ها به گرید نمونه‌کار می‌پرند و داخل گوشی می‌روند؛ امکانات سایت: استعلام، رزرو، ارسال محصول از هر شهر، گالری |
| ۲۶٫۳ تا ۳۰ | دعوت به اقدام: 3evda.com، دکمه‌ی استعلام، اینستاگرام، و لوپ به ابتدا |

## ساخت

1. عکس‌ها را در `photos/` بگذارید (یا `tools/fetch_site_photos.py` را داخل ایران اجرا کنید).
2. `./build.sh` (نیاز: Python 3 با numpy، scipy و Pillow؛ Node؛ Playwright با Chromium؛ ffmpeg)

خروجی‌ها در `build/`: `reel.mp4`، `reel-silent.mp4` (برای استفاده از آهنگ ترند اینستاگرام)، `cover.png`.
تا وقتی عکسی در `photos/` نباشد، تصاویر موقت انتزاعی به‌کار می‌روند و برچسب قرمز «PLACEHOLDER» روی ویدیو می‌آید.
